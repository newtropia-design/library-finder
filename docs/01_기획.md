# 1단계 기획: 가까운 공공도서관 찾기

## 사용자와 문제
- **사용자**: 집 근처 도서관을 찾거나, 여러 도서관의 거리를 비교하려는 일반 시민
- **문제**: 여러 도서관 정보를 따로 찾아보고 직접 거리를 계산하기 번거롭다

## 화면 흐름
1. 현재 위치(주소 또는 위도·경도)를 입력한다
2. 도서관 목록이 직선거리 가까운 순서로 표시된다
3. 목록에서 도서관을 고르면 상세 정보(이름, 주소, 운영시간)가 보인다

## 기능 목록

| ID | 기능 | 설명 | 필요한 데이터 | 구분 |
|---|---|---|---|---|
| F1 | 위치 입력 | 위도·경도를 입력하거나 예시 위치 버튼 사용 | 없음 | MVP |
| F2 | 도서관 목록 | 도서관 이름, 주소, 위도·경도 목록 | 도서관 데이터 | MVP |
| F3 | 거리 계산·정렬 | 입력 위치에서 직선거리(km) 계산, 가까운 순 정렬 | F1 + F2 | MVP |
| F4 | 상세 보기 | 선택한 도서관의 주소와 운영시간 표시 | F2 | MVP |
| F5 | 실제 데이터 연결 | 공공데이터 API로 실제 도서관 목록 조회 | 공공 API | 다음 확장 |

## MVP 범위
F1 ~ F4 (5개 이내). F5는 API 키 발급과 명세 확인 뒤에 추가한다.

## 데이터 원칙
- 현재 저장된 도서관 데이터는 **예시 데이터**다. 이름에 "예시"를 붙이고 화면에 [예시 데이터] 표시를 보여준다.
- 거리는 모두 **직선거리**다. 도보 시간은 계산하지 않는다.
