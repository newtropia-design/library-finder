# 4단계 보고서: 가까운 도서관 찾기

> 조사 기준일: 2026-11-27

## 1. 기능 정의
F1 위치 입력, F2 도서관 목록, F3 거리 계산·정렬, F4 상세 보기 (MVP). F5 실제 데이터 연결은 다음 확장. 자세한 내용은 [01_기획.md](01_기획.md).

## 2. API 조사·선정
전국 단위 도서관 좌표를 주는 공식 API를 검색으로 확인하지 못했습니다. 이번 버전은 **예시 데이터**로 동작합니다. 자세한 내용은 [02_API_선정.md](02_API_선정.md).

## 3. 구현
- 서버: Express 5, `/api/libraries`, `/api/nearby?lat=&lng=`
- 거리: 하버사인 공식 기반 직선거리
- 화면: 위치 입력, 가까운 순 목록, 상세 보기, [예시 데이터] 표시
- 구조: [03_설계.md](03_설계.md)

## 4. 검증 결과

| 항목 | 결과 |
|---|---|
| `npm test` (거리 계산·정렬) | 통과 |
| `/api/libraries` | 200, 예시 5곳 반환 |
| `/api/nearby` (정상 좌표) | 200, 거리순 정렬 확인 |
| `/api/nearby` (잘못된 좌표) | 400, 한국어 오류 메시지 |
| 브라우저 화면 (로컬) | 목록 표시, 예시 위치 버튼 동작, 콘솔 오류 없음 |
| Vercel 배포 | **미실행** (아래 참고) |

### 검증 중 발견한 문제와 수정
- `server.js`가 `dotenv`를 불러오는데 `package.json`에 없어서 서버가 실행되지 않았습니다. `npm install dotenv`로 추가해 해결했습니다.

## 6. 사용자가 직접 할 일
1. 터미널에서 `vercel login` 실행 후 브라우저에서 승인
2. 이 프롬프트를 다시 붙여 넣고 "이어서 배포해 줘"라고 요청
3. (선택) 공공데이터포털에서 "공공도서관" 데이터의 좌표 항목을 확인하고 활용신청
