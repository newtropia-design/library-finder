# 2단계 API 선정

> 조사 기준일: 2026-11-27 (검색 결과 기준, 정책은 바뀔 수 있으므로 활용신청 전 공식 페이지에서 다시 확인)

## 후보 조사

| 후보 | 제공기관 | 내용 | 평가 |
|---|---|---|---|
| 국토교통부 작은도서관 | 국토교통부 | 작은도서관 목록, JSON·XML, 무료 | 공공도서관이 아니라 대상이 다름. 좌표 항목은 확인 필요 |
| 세종특별자치시 도서관 조회 서비스 | 세종특별자치시 | 도서관 위치 경도 좌표 옵션 있음 | 지역이 세종시로 한정됨 |
| 전북특별자치도 공공도서관 현황 | 전북특별자치도 | 공공도서관 대상 | 좌표 항목은 명시되지 않음 |
| 경기도 사이버도서관 도서관정보 | 경기도 | 파일형 데이터, GPS_X·GPS_Y 포함 | API가 아니라 파일 데이터 |

출처: 공공데이터포털 검색 결과 (data.go.kr 의 15101084, 15098368, 15148757 등 데이터셋 페이지)

## 선정 기준 평가

| 기준 | 전국 단위 좌표 제공 API |
|---|---|
| ① 공식 데이터 | 해당 없음 (공공기관 데이터) |
| ② 필요한 항목(좌표) 제공 | **확인되지 않음** |
| ③ 무료·호출량 | 대부분 무료 (명세 확인 필요) |
| ④ 서버에서만 키 사용 | 가능 (일반 공공데이터 API 방식) |
| ⑤ 비전공자가 발급 | 가능 |

## 결론
- **전국 단위로 좌표를 주는 공식 API를 검색으로 확인하지 못했습니다.**
- 따라서 이번 버전은 **예시 데이터**로 동작하고, 실제 API 연결은 **다음 확장**으로 둡니다.
- 사용자가 직접 할 일: 공공데이터포털에서 "공공도서관" 데이터셋의 요청·응답 변수에 좌표가 있는지 확인한 뒤 활용신청.

## 제외 이유 요약
- 작은도서관 API: 공공도서관이 아님
- 세종·전북 API: 지역 한정, 좌표 항목 불확실
- 경기도 파일 데이터: API가 아님
