# 3단계 설계

## 구조
```
브라우저 (public/) ── GET /api/libraries ──▶ Express 서버 (app.js)
                                           │ data/libraries.json 읽기 (예시 데이터)
                                           ▼
                                    거리 계산 (하버사인 공식) → 가까운 순 정렬
```

## 폴더 구조

| 파일 | 역할 |
|---|---|
| `app.js` | Express 앱, `/api/libraries` 라우트 |
| `server.js` | 로컬 실행용 진입점 (포트 3000) |
| `api/index.js` | Vercel 서버리스 진입점 (app.js 내보내기) |
| `lib/distance.js` | 직선거리 계산 |
| `lib/libraries.js` | 도서관 데이터 읽기, 거리 계산·정렬 |
| `data/libraries.json` | 예시 도서관 데이터 (이름에 "예시" 포함) |
| `public/index.html`, `public/css/style.css`, `public/js/app.js` | 화면 |
| `vercel.json`, `.vercelignore`, `.gitignore`, `.env.example` | 배포·설정 |

## 캐시 정책
- 예시 데이터는 파일에서 읽으므로 캐시하지 않는다.
- 나중에 공공 API를 붙이면, 약관상 저장이 가능한 응답만 짧게 캐시한다.

## 키 정책
- 현재는 키가 필요 없다.
- 나중에 키를 쓰게 되면 `.env`에만 두고, 브라우저로 보내지 않는다.
